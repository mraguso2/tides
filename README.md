# Eatons Neck Tides

A simple, community-focused tide tracker for **Eatons Neck, NY** - built for the boaters, fishermen, and waterfront folks of Northport, Centerport, and Huntington Harbor.

## What It Does

Displays daily and future high and low tide times for Eatons Neck so you can plan your day on the water without digging through NOAA tables.

## v1 Tech Stack

- [Next.js](https://nextjs.org/) 13
- React 18
- date-fns

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying

Deploy instantly with [Vercel](https://vercel.com/) — the easiest path for Next.js apps.
